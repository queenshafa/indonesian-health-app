================================================================================
🎯 CLIENT-SIDE CHANGES
================================================================================

FROM:
  const result = await fetch('/api/symptoms/analyze').then(r => r.json())
  // User waits 2-30 seconds ❌

TO:
  const { job_id } = await fetch('/api/symptoms/analyze').then(r => r.json())
  const { job, isCompleted } = useAsyncJob(job_id, { autoStart: true })
  // User sees results instantly, polling happens in background ✅

💡 TROUBLESHOOTING REFERENCE
================================================================================

Problem: "Jobs stuck in pending"
Solution: Check N8N_WEBHOOK_URL is set and N8N is running

Problem: "Webhook not reaching N8N"
Solution: Verify webhook URL is reachable, check N8N logs

Problem: "Results not saving to database"
Solution: Check webhook handler, verify async_jobs table exists

Problem: "High polling CPU usage"
Solution: Increase pollInterval in useAsyncJob hook
