═══════════════════════════════════════════════════════════════
  YANG HARUS ANDA LAKUKAN SEKARANG:
═══════════════════════════════════════════════════════════════

1. BUKA N8N
   - Login ke N8N account Anda
   - Buka atau buat workflow untuk handle jobs
   - Copy webhook URL

2. SET VARIABLE DI VERCEL
   - Pergi ke Vercel project
   - Settings → Environment Variables
   - Tambah variabel baru:
   
   Name: N8N_WEBHOOK_URL
   Value: [paste webhook URL dari N8N]
   Environments: Production, Preview, Development
   
   Klik Save

3. REDEPLOY
   - Vercel akan auto-redeploy
   - Atau trigger redeploy manual
